## RIGIS Website
<br>
Este proyecto es una página web básica desarrollada como parte de un _curso de Front-End de Talento Tech. La temática sera un sitio web para la Residencia de Gestion en Salud - GCBA a la que pertenezco.<br>
La página está estructurada con HTML semántico y utiliza las etiquetas __<header>__, __<main>__, y __<footer>__ para organizar el contenido. <br>
<br>
El objetivo es aprender a crear la estructura básica de una página web aplicarle formato con CSS y prepararla para aplicarle JavaScript.
