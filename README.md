## RIGIS Website
<br>
Este proyecto es una __página web básica__ desarrollada como parte de un _curso de Front-End de Talento Tech_. La temática sera un sitio web para la Residencia de Gestion en Salud - GCBA.<br>
La página está estructurada con HTML semántico y utiliza las etiquetas __<header>__, __<main>__, y __<footer>__ para organizar el contenido. <br>
El objetivo es aprender a crear la estructura básica de una página web y prepararla para futuras mejoras con CSS y JavaScript.
