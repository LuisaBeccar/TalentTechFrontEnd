# RIGIS Website

> Sitio web institucional desarrollado para la **Residencia de Gestión en Salud (GCBA)**.

---

## Descripción del Proyecto
Este proyecto fue desarrollado como parte del curso de **Front-End** de **Talento Tech**. Consiste en la creación de un sitio web pensado para la **Residencia Interdisciplinaria de Gestión Integral de Información en Salud Publica del GCBA**, buscando optimizar la presentación de información institucional de manera clara y accesible.

## Características Principales
* **HTML Semántico:** Organización del contenido utilizando etiquetas modernas y accesibles como `<header>`, `<main>` y `<footer>`.
* **Diseño Base:** Estructura preparada para aplicar estilos visuales mediante CSS.
* **Escalabilidad:** Código ordenado y listo para integrar interactividad con JavaScript.

## Objetivos de Aprendizaje
* Dominar la estructura base de una página web utilizando buenas prácticas de marcado.
* Aplicar diseño y formato mediante hojas de estilo (CSS).
* Preparar el terreno para la manipulación del DOM y la lógica con JavaScript.
